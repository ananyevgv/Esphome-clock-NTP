# Clock-G2 — умные часы на ESP8266

[![ESPHome](https://img.shields.io/badge/ESPHome-2024.4.0-blue)](https://esphome.io/)

Четвертая версия

Умные часы с автоматической регулировкой яркости и синхронизацией времени через интернет.  
Собраны на базе **WEMOS D1 mini** с использованием **ESPHome**.

<img src="./clock-4.jpg" height="300" alt="Часы">
---

## 📋 Особенности

- ⏰ Отображение времени на 4-разрядном дисплее TM1637
- 🌐 Автоматическая синхронизация времени через NTP (SNTP)
- 🔋 Сохранение времени в RTC DS1307 при отключении питания
- ☀️ Автоматическая регулировка яркости по освещённости (фоторезистор)


---

## 🛠️ Аппаратная часть

### Компоненты
| Компонент | Модель | Назначение |
|-----------|--------|------------|
| Микроконтроллер | WEMOS D1 mini (ESP8266) | Управление |
| Дисплей | TM1637 (4-разрядный) | Отображение времени |
| RTC | DS1307 (I²C) | Ход времени |
| Датчик освещённости | Фоторезистор | Регулировка яркости |
